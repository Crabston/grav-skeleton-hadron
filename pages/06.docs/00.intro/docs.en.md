## What is Hadron?
[span class="hadron-font"]Hadron[/span] is more than a modern and customizable [Grav](https://getgrav.org/) theme and skeleton. On the one hand, it is optimized for beginners to quickly create a simple website, but on the other hand, it is also suitable for professionals who want to use Hadron as a foundation for a complex website with self-developed functions.

The Hadron theme is based on [Quark2](https://github.com/getgrav/grav-theme-quark2). It enhances Quark2 with additional features and customization options Quark2 doesn't support. There are also new page templates and other elements that are not part of Quark2. If you are already using Quark or Quark2, you can easily switch to Hadron by installing the Hadron theme and changing the theme in the Grav configuration.

## What is the difference between the Hadron Skeleton & Theme?
[span class="hadron-font"]Hadron[/span] comes in 2 variants: as a theme and as a skeleton.

The theme is a modular part of Grav. Similar to plugins, themes can be installed more or less freely. Depending on the theme, there are different types of pages that can be used, as well as other options to edit the behavior of the page.

The skeleton is a larger part of Grav. It includes the entire `/user` folder, which acts as the customizable part of a website made with Grav, including the Hadron theme itself. More precisely, this includes pages, configurations, plugins, themes, and possibly also accounts and other data.

Thus, the skeleton can be used as a ready-made template for a website, which can be edited and published directly. The theme, however, requires an existing page.

## Should I use the Skeleton or the Theme?
Depending on the use case, it is better to use the skeleton or the theme.

### Why the Skeleton?
You should use the Hadron skeleton in the following cases:
- you want a ready-to-use website that you can simply edit
- you are looking for an easy way to get started with Grav CMS
- you want to try out Hadron yourself

### When the Theme?
In the following cases, it makes more sense to use the theme instead of the skeleton:
- you have already created a page with Grav and are looking for a (different) theme
- you use the Quark2 theme but want more features
- you do not want to use a website template but build everything from scratch

## Features of Hadron
The Hadron theme offers the following features:
- Ready-to-use language switcher for multilingual sites
- Unique support for responsive tables
- Menu with dropdown support and customizable menu items
- More theme customization options
- Built-in Support for H5P
- Built-in Support for Embed.ly
- more German translations
- Featured posts in blogs

### Skeleton-only features:
These features are only available through the skeleton:
- **Ready-to-use Grav instance with Hadron theme**
- Full website template with examples for websites with optional webshop
- Configured for multilingual and can be easily extended to support other languages
- Many standard features that are needed for most websites already included
- Pre-defined groups configuration to easily manage user permissions via admin
- Pre-installed plugins + pre-setup config to enhance the site for publishing
- Pre-setup config for SendGrid email support
- Pre-setup config for Doppler secrets manager

### Features adopted from Quark 2
The following features have been adopted from the Quark theme:
- Modern design system, made with [BladesCSS](https://blades.ninja/)
- Font Awesome 7 icon set with free CDN
- Light & Dark mode with OS preference detection
- Configurable accent color to match your brand
- Fully responsive including mobile navigation
- Built-in support for on-page navigation (single-page sites)
- _and much more_

## A glimpse into Hadron's next features
In the future, Hadron should have additional features for both the theme and the skeleton:
- more design options configurable directly in admin panel
- more page templates for different use cases
- more configuration options for pages via admin panel
- more accessibility features
- further guides and tutorials to use Hadron or just Grav in general
- further translations of other extensions
- various optimizations & improvements
