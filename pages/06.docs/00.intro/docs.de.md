## Was ist Hadron?
[span class="hadron-font"]Hadron[/span] ist mehr als nur ein modernes und anpassbares [Grav](https://getgrav.org/) Theme und Skeleton. Einerseits ist es für Einsteiger optimiert, um schnell eine einfache Website zu erstellen; andererseits eignet es sich auch für Profis, die Hadron als Grundlage für eine komplexe Website mit selbstentwickelten Funktionen nutzen möchten.

Das Hadron Theme basiert auf [Quark2](https://github.com/getgrav/grav-theme-quark2). Es erweitert Quark2 mit zusätzlichen Funktionen und Anpassungsoptionen, die Quark2 nicht bietet. Ausserdem gibt es neue Seiten Vorlagen und weitere Elemente, die nicht Teil von Quark2 sind. Wenn du bereits Quark oder Quark2 verwendest, kannst du einfach zu Hadron wechseln, indem du das Hadron Theme installierst und das Theme in den Grav Einstellungen anpasst.

## Was ist der Unterschied zwischen dem Hadron Skeleton & Theme?
[span class="hadron-font"]Hadron[/span] gibt es in 2 Varianten: als Theme und als Skeleton.

Das Theme ist ein modularer Bestandteil von Grav. Ähnlich wie Plugins können Themes mehr oder weniger frei installiert werden. Je nach Theme gibt es verschiedene Seitentypen, die verwendet werden können, sowie weitere Optionen, um das Verhalten der Seite zu bearbeiten.

Das Skeleton ist ein grösserer Bestandteil von Grav. Es enthält den gesamten `/user` Ordner, der als anpassbarer Teil einer mit Grav erstellten Website dient, einschliesslich des Hadron Themes selbst. Genauer gesagt umfasst dies Seiten, Konfigurationen, Plugins, Themes und gegebenenfalls auch Konten und andere Daten.

Das Skeleton kann somit als sofort einsatzbereite Vorlage für eine Website verwendet werden, die direkt bearbeitet und veröffentlicht werden kann. Das Theme hingegen erfordert eine bereits vorhandene Seite.

## Sollte ich das Skeleton oder das Theme verwenden?
Je nach Anwendungsfall ist es besser, das Skeleton oder das Theme zu verwenden.

### Warum das Skeleton?
Du solltest das Hadron Skeleton in den folgenden Fällen verwenden:
- du möchtest eine einsatzbereite Website, die du einfach bearbeiten kannst
- du suchst einen einfachen Einstieg in das Grav CMS
- du möchtest Hadron selbst ausprobieren

### Wann das Theme?
In den folgenden Fällen ist es sinnvoller, das Theme anstelle des Skeletons zu verwenden:
- du hast bereits eine Seite mit Grav erstellt und suchst ein (anderes) Theme
- du verwendest das Quark2 Theme, möchtest aber mehr Funktionen
- du möchtest keine Website Vorlage verwenden, sondern alles von Grund auf selbst erstellen

## Funktionen von Hadron
Das Hadron Theme bietet folgende Funktionen:
- Fertig eingebauter Sprachschalter für mehrsprachige Websites
- Einzigartige Unterstützung für responsive Tabellen
- Menü mit Dropdown Unterstützung und anpassbaren Menüpunkten
- Mehr Theme Anpassungsoptionen
- Eingebaute Unterstützung für H5P
- Eingebaute Unterstützung für Embed.ly
- bessere deutsche Übersetzungen

### Nur im Skeleton verfügbare Funktionen:
Diese Funktionen sind nur im Skeleton verfügbar:
- **Einsatzbereites Grav System mit dem Hadron Theme**
- Vollständige Website Vorlage mit Beispielen und optionalem Webshop
- Konfiguriert für Mehrsprachigkeit und leicht in andere Sprachen erweiterbar
- Viele Standardfunktionen, die für die meisten Websites benötigt werden, sind bereits enthalten
- Vorgefertigte Gruppen Konfiguration zur einfachen Verwaltung von Benutzerrechten über das Admin Plugin
- Vorinstallierte Plugins + vorkonfigurierte Einstellungen zur Vereinfachung bei der Veröffentlichung
- Vorgefertigte Konfiguration für SendGrid E-Mail
- Vorgefertigte Konfiguration für Doppler Secrets Manager

### Von Quark2 übernommene Funktionen
Die folgenden Funktionen wurden aus dem Quark Theme übernommen:
- Modernes Designsystem, erstellt mit [BladesCSS](https://blades.ninja/)
- Font Awesome 7 Icon Set über kostenloses CDN
- Hell- & Dunkelmodus mit OS Präferenz Erkennung
- Konfigurierbare Akzentfarbe zur Anpassung an deine Marke
- Vollständig responsiv inklusive mobiler Navigation
- Eingebaute Unterstützung für On-Page Navigation (Single-Page Websites)
- _und vieles mehr_

## Ein Blick auf Hadrons nächste Funktionen
In Zukunft soll Hadron sowohl für das Theme als auch das Skeleton zusätzliche Funktionen erhalten:
- Mehr Designoptionen, die direkt im Admin Panel konfigurierbar sind
- Mehr Seitentemplates für unterschiedliche Anwendungsfälle
- Mehr Konfigurationsoptionen für Seiten über das Admin Panel
- Verbesserte Barrierefreiheitsfunktionen
- Weitere Anleitungen und Tutorials zur Nutzung von Hadron resp. Grav im Allgemeinen
- Weitere Übersetzungen anderer Erweiterungen
- Verschiedene Optimierungen & Verbesserungen
