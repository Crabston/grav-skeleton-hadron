## Introduction
The [span class="hadron-font"]Hadron[/span] Theme is part of the [Hadron Skeleton](/docs/skeleton) and is based on [Quark2](https://github.com/getgrav/grav-theme-quark2). It enhances Quark2 with additional features and customization options Quark2 doesn't support. There are also new page templates and other elements that are not part of Quark2.

If you are already using Quark or Quark2, you can easily switch to Hadron by installing the Hadron theme and changing the theme in the Grav configuration.

## Hadron
[span class="hadron-font"]Hadron[/span] comes in 2 variants: as a theme and as a skeleton. Learn more about that on the [Hadron Introduction](/docs/intro).

## Features
The Hadron Theme offers the following features:

### Ready-to-use language switcher for multilingual sites
A language switcher is included in the header of the site, permitting users to switch between different languages when the site is configured for multilingual support. The appearance and behavior of the language switcher can be customized in the theme configuration.

### Unique support for responsive tables
Tables can be automatically optimized for mobile devices. This means that tables are displayed differently on mobile devices to improve readability. Learn more about mobile-friendly tables at the [Elements page](/elements#mobile-friendly-tables).

### Menu with dropdown support and customizable menu items
The menu / navigation in the header can be enhanced with a drop-down menu. This allows not only the main pages but also the subpages to be displayed in the navigation.

### More theme customization options
The Hadron theme offers more configuration options for theme & pages to customize the appearance and behavior of the site. Learn more about the theme options in the [Theme Options](/docs/theme/options).

### Built-in Support for H5P
H5P is a framework for creating interactive content. The Hadron Theme supports H5P to embed interactive content in Grav.

### Built-in Support for Embed.ly
Embed.ly is a service that allows embedding content from other websites. The Hadron Theme supports Embed.ly to embed content from other websites.

### more German translations
The Hadron theme includes a more complete German language pack used in the Admin and the front-end of the site if German pages are used.

### Featured posts in blogs
In blog pages, posts can be pinned to feature them. This is particularly useful for marking important posts or announcements.

### Other enhancements
The Hadron theme also includes other small, not notable enhancements to improve the user experience and customize the theme to the users' needs.
