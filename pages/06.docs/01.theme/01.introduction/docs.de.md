## Einführung
Das [span class="hadron-font"]Hadron[/span] Theme ist Teil des [Hadron Skeleton](/docs/skeleton) und basiert auf [Quark2](https://github.com/getgrav/grav-theme-quark2). Es erweitert Quark2 mit zusätzlichen Funktionen und Anpassungsoptionen, die Quark2 nicht bietet. Es gibt auch neue Seiten Vorlagen und weitere Elemente, die nicht Teil von Quark2 sind.

Falls du bereits Quark oder Quark2 nutzt, kannst du einfach zu Hadron wechseln, indem du das Hadron Theme installierst und das Theme in den Grav Einstellungen änderst.

## Hadron
[span class="hadron-font"]Hadron[/span] gibt es in 2 Varianten: als Theme und als Skeleton. Erfahre mehr darüber auf der [Hadron Einführung](/docs/intro).

## Funktionen
Das Hadron Theme bietet folgende Funktionen:

### Fertig einsatzbereiter Sprachschalter für mehrsprachige Websites
Ein Sprachschalter ist im Website Header enthalten, der es dir ermöglicht, zwischen verschiedenen Sprachen zu wechseln, wenn die Website für Mehrsprachigkeit konfiguriert ist. Das Aussehen und Verhalten des Sprachumschalters kann in den Theme Einstellungen angepasst werden.

### Einzigartige Unterstützung für responsive Tabellen
Tabellen können automatisch für mobile Geräte optimiert werden. Das bedeutet, dass Tabellen auf mobilen Geräten anders dargestellt werden, um die Lesbarkeit zu verbessern. Erfahre mehr über mobile-freundliche Tabellen auf der [Elemente Seite](/elemente#mobilfreundliche-tabellen).

### Menü mit Dropdown Unterstützung und anpassbaren Menüpunkten
Das Menü / die Navigation im Header kann mit einem Dropdown Menü erweitert werden. Dies ermöglicht es, nicht nur die Hauptseiten, sondern auch die Unterseiten in der Navigation anzuzeigen.

### Mehr Theme Anpassungsoptionen
Das Hadron Theme bietet mehr Konfigurationsoptionen für Theme & Seiten, um das Aussehen und Verhalten der Website anzupassen. Erfahre mehr über die Theme Optionen in den [Theme Optionen](/docs/theme/optionen).

### Eingebaute Unterstützung für H5P
H5P ist ein Framework zum Erstellen interaktiver Inhalte. Das Hadron Theme unterstützt H5P, um interaktive Inhalte in Grav einzubetten.

### Eingebaute Unterstützung für Embed.ly
Embed.ly ist ein Service, der das Einbetten von Inhalten von anderen Websites ermöglicht. Das Hadron Theme unterstützt Embed.ly, um Inhalte von anderen Websites einzubetten.

### Bessere deutsche Übersetzungen
Das Hadron Theme enthält ein vollständigeres deutsches Sprachpaket mit mehr Übersetzungen, das in der Adminoberfläche und auf der Website verwendet wird, wenn deutsche Seiten angezeigt werden. So sind Grav, Admin und Seiten vollständig auf Deutsch übersetzt.

### Hervorgehobene Beiträge in Blogs
Auf Blog Seiten können Beiträge gefeatured werden, um sie hervorzuheben. Dies ist besonders nützlich, um wichtige Beiträge oder Ankündigungen zu kennzeichnen.

### Weitere Verbesserungen
Das Hadron Theme enthält auch weitere kleine, nicht unbedingt erwähnenswerte Verbesserungen, um die Benutzererfahrung zu verbessern und das Theme nach deinen Bedürfnissen anzupassen.
