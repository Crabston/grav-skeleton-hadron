## Introduction
This hadron Skeleton includes the [Hadron Theme](/docs/theme) itself, plus a ready-to-use user folder with examples, templates and much more to start building upon our templates to create a new website easily using Grav CMS.

## Hadron
Hadron comes in 2 variants: as a theme and as a skeleton. Learn more about that on the [Hadron Introduction](/docs/intro).

## Features
The Hadron Skeleton includes the following features:

### Ready-to-use Grav instance with Hadron theme
The Hadron Skeleton is a ready-to-use boilerplate for a website that can be edited and published directly. This allows you to quickly and easily create a website with Grav without having to start from scratch.

### Full website template with examples for websites with optional webshop
It includes various example pages and templates that serve as a starting point for creating a new website.

### Configured for multilingual and can be easily extended to support other languages
The website is configured for multilingual support and can be easily extended to support additional languages.

### Many standard features that are needed for most websites already included
Features most websites require out of the box are included, such as SEO, contact forms, blogging, and much more.

### Pre-defined groups configuration to easily manage user permissions via admin
Default groups for optimal user permissions are already defined. This allows users with different permissions to be created to ensure the security of the website.

### Pre-installed plugins + pre-setup config to enhance the site for publishing
A selection of plugins and themes are already installed and configured, as other configuration is done already. This makes publishing a new website much easier by reducing the amount of setup required.

### Pre-setup config for SendGrid email support
In addition to the email configuration, there is also an optional, default configuration for SendGrid Email. This allows emails to be sent via SendGrid (**own account needed!**). This function supports the Doppler Secrets Manager.

### Pre-setup config for Doppler secrets manager
An additional feature of this skeleton is the default configuration for the Doppler Secrets Manager. This allows secret information such as API keys, passwords and other sensitive data to be securely stored and retrieved (**own account needed!**).

For this feature, our [modified Grav Core](https://github.com/Crabston/grav) is required, so that these can be automatically fetched by Doppler.
