## Einführung
Dieses Hadron Skeleton enthält das [Hadron Theme](/docs/theme) selbst sowie einen einsatzbereiten `user` Ordner mit Beispielen, Vorlagen und vielem mehr. So kannst du schnell auf unseren Vorlagen aufbauen und mit Grav CMS einfach eine neue Website erstellen.

## Hadron
Hadron gibt es in zwei Varianten: als Theme und als Skeleton. Mehr dazu findest du auf der [Hadron Einführung](/docs/intro).

## Funktionen
Das Hadron Skeleton beinhaltet folgende Funktionen:

### Einsatzbereites Grav System mit dem Hadron Theme
Das Hadron Skeleton ist eine einsatzbereite Vorlage für eine Website, die du direkt bearbeiten und veröffentlichen kannst. Damit kannst du schnell und unkompliziert eine Website mit Grav erstellen, ohne bei Null anfangen zu müssen.

### Vollständige Website Vorlage mit Beispielen und optionalem Webshop
Es enthält verschiedene Beispielseiten und Vorlagen, die als Ausgangspunkt für die Erstellung einer neuen Website dienen.

### Konfiguriert für Mehrsprachigkeit und leicht in andere Sprachen erweiterbar
Die Website ist für Mehrsprachigkeit konfiguriert und lässt sich leicht erweitern, um zusätzliche Sprachen zu unterstützen.

### Viele Standardfunktionen, die für die meisten Websites benötigt werden, sind bereits enthalten
Funktionen, die die meisten Websites brauchen, sind bereits enthalten, zum Beispiel SEO, Kontaktformulare, Blog Funktionen und vieles mehr.

### Vorgefertigte Gruppen Konfiguration zur einfachen Verwaltung von Benutzerrechten über das Admin Plugin
Vordefinierte Gruppen für optimale Benutzer Rechte sind bereits eingerichtet. So kannst du Benutzer mit unterschiedlichen Rechten anlegen, um die Sicherheit der Website sicherzustellen.

### Vorinstallierte Plugins + vorkonfigurierte Einstellungen zur Vereinfachung bei der Veröffentlichung
Eine Auswahl an Plugins und Themes ist bereits installiert und vorkonfiguriert. Dadurch reduziert sich der Aufwand für das Setup und das Veröffentlichen einer neuen Website wird einfacher.

### Vorgefertigte Konfiguration für SendGrid E-Mail
Neben der E-Mail Konfiguration gibt es eine optionale Standardkonfiguration für SendGrid E-Mail. Damit können E-Mails über SendGrid versendet werden (**eigenes Konto benötigt!**). Diese Funktion unterstützt den Doppler Secrets Manager.

### Vorkonfigurierte Einstellungen für den Doppler Secrets Manager
Eine weitere Funktion dieses Skeletons ist die Standardkonfiguration für den Doppler Secrets Manager. Damit können vertrauliche Informationen wie API Keys, Passwörter und andere sensible Daten sicher gespeichert und abgerufen werden (**eigenes Konto benötigt!**).

Für diese Funktion wird unser [angepasster Grav Core](https://github.com/Crabston/grav) benötigt, damit diese automatisch von Doppler abgerufen werden können.
